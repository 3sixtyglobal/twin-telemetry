# Interface: ITelemetryServiceConstructorOptions

The options for the telemetry service constructor.

## Properties

### telemetryConnectorType? {#telemetryconnectortype}

> `optional` **telemetryConnectorType?**: `string`

The type of the telemetry connector to use.

#### Default

```ts
telemetry
```

***

### tenantComponentType? {#tenantcomponenttype}

> `optional` **tenantComponentType?**: `string`

The type of the tenant component to use for partition iteration.

#### Default

```ts
tenant
```
